# Casa Brasa | Burgers al carbón 🍔

Landing page para **Casa Brasa**, servicio de comida a domicilio en Oiba, Santander, especializado en burgers al horno brasa.

## 🔗 Demo

Puedes ver el proyecto abriendo el archivo `index.html` en tu navegador.

## 📋 Secciones de la página

- **Inicio**: presentación y botón de pedido.
- **Menú**: tarjetas con las burgers disponibles.
- **Nosotros**: breve historia del negocio.
- **Contacto**: botón directo a WhatsApp para hacer pedidos.

## 🛠️ Tecnologías

- HTML5
- CSS3
